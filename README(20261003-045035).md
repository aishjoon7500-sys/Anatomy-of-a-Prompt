# What Makes a Good AI Prompt?

Artificial intelligence tools can generate impressive results, but the quality of those results often depends on how clearly the user communicates with the AI.

A **good AI prompt** is not necessarily a long prompt. It is a prompt that provides enough information for the AI to understand the objective, context, expected output, and any limitations.

## 1. Define the Role

Tell the AI what role or perspective it should use.

**Example:**

> Act as a data analyst with experience in business reporting.

This gives the AI a clearer perspective when generating its response.

## 2. Clearly State the Task

Describe exactly what you want the AI to accomplish.

**Weak prompt:**

> Analyze this data.

**Better prompt:**

> Analyze the sales data and identify the three products with the highest revenue and any significant monthly trends.

The second version gives the AI a specific objective.

## 3. Provide Context

Context helps the AI understand the situation surrounding the task.

For example:

> This analysis will be presented to a non-technical business team. The dataset contains monthly sales from January to December.

Without context, the AI may make assumptions about the purpose or audience.

## 4. Specify the Audience

The same information can be presented differently depending on who will read it.

You can specify:

- Beginners
- Technical users
- Managers
- Clients
- Students
- General audiences

**Example:**

> Explain the findings for a business manager who has limited knowledge of statistics.

## 5. Specify the Output Format

Tell the AI how you want the response structured.

For example:

> Present the findings in a table with the columns: Product, Revenue, Growth Rate, and Key Observation.

You can request formats such as:

- Bullet points
- Tables
- Step-by-step instructions
- Reports
- JSON
- Code
- Summaries

## 6. Define the Tone and Style

The same content can be written in different styles.

For example:

> Write in a concise, professional, and easy-to-understand tone.

Other possibilities include:

- Formal
- Conversational
- Technical
- Friendly
- Academic
- Concise

## 7. Add Constraints

Constraints help prevent unwanted or overly broad responses.

Examples:

> Keep the answer under 300 words.

> Use only the information provided.

> Do not make assumptions about missing values.

> Provide three examples.

## A Practical Prompt Template

A useful structure is:

```text
Role:
[Who should the AI act as?]

Task:
[What should the AI do?]

Context:
[What information does the AI need?]

Audience:
[Who will use the output?]

Format:
[How should the answer be structured?]

Tone:
[What style should be used?]

Constraints:
[What limitations or rules should be followed?]
```

## Example of a Complete Prompt

```text
Act as a data analyst.

Analyze the provided sales dataset and identify the
main revenue trends and unusual values.

The dataset contains monthly sales data for multiple
products. The analysis will be presented to a
non-technical business team.

Present the findings in a table followed by five
key insights.

Use a professional and concise tone.

Use only the information available in the dataset
and do not assume values that are not provided.
```

## Final Takeaway

Effective prompting is less about **writing longer instructions** and more about **providing the right instructions**.

A well-structured prompt gives AI the information it needs to produce an output that is more relevant, consistent, and aligned with the user's objective.

**Role + Task + Context + Audience + Format + Tone + Constraints = a strong starting point for an effective AI prompt.**
